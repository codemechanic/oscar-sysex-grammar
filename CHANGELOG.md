# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/).

## [1.1.0] - 2026-10-29

### Fixed
- Updated embedded Python scripts to Python 3 syntax for compatibility with Synalyze It! Pro 1.26+
- Fixed HTML entities in standalone Python script (`>>` and `&` operators)

## [1.0.0] - Initial Release

### Added
- OSCar MIDI Sysex grammar for Synalyze It! and Hexinator
- Tauntek MIDI Sysex grammar with support for new hardware and firmware features
- Python scripts for OSCar Exclusive Data Format and patch byte parsing
- Factory patch and wavetable sysex file
- Factory patch names list
